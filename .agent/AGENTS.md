# Agent Guidelines and Best Practices

> [!IMPORTANT]
> **Resource Management**: Always remember to close or terminate any running background tasks and tests as soon as they have served their purpose to free up system resources.

> [!IMPORTANT]
> **Git Workflow**: DO NOT modify or touch other copies of the repository on the user's machine (e.g., in `/Users/chang/git/`). ONLY make code modifications within the local Antigravity workspace (`/Users/chang/Anitgravity/chess/`) and use `git commit` and `git push` so the user can pull the changes into their own preferred workspace.
